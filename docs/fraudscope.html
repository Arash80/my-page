Problem

Agent-generated analysis can be difficult to trust when models calculate statistics differently, execute arbitrary code, or send sensitive data to hosted services.

My contribution

Built an AutoGen AgentChat workflow with separate code-writer, executor, and analyst roles; local Qwen inference through Ollama; strict approval rules for generated Python; deterministic pandas profiling; bounded repair rounds; and offline unit and integration tests.

Engineering result

The agents coordinate and verify the workflow, but trusted code produces the statistics. Each run creates machine-readable JSON, Markdown summaries, column-level CSV reports, missing-data analysis, and a complete labeled agent log.

Interfaces

A Streamlit dashboard supports CSV upload, live agent messages, dataset previews, charts, report inspection, and ZIP downloads. The same workflow is available through a CLI and a clean Jupyter notebook.

Execution safeguards

Generated code runs only when its syntax, imports, paths, profiler arguments, and output call match the approved wrapper. Deviations are rejected and returned to the agents for correction.

Privacy and reproducibility

Models and execution remain local, generated outputs are isolated from source control, and the deterministic profiler can run independently without AutoGen or Ollama.
